# Archive

[Documentation index](../README.md)

Records from harnesses that are no longer on `main` (2026-10-18 to 2026-11-11): personal browsing, coexistence,
component gallery, external/MiniWoB++, hostile UI and shared-browser stress tracks, plus Kitsune A/B experiments.
They are not instructions for the current runner, and their numbers are not comparable with the current suite.

- [Archived result reports](results/README.md) and the same reports [grouped by Kitsune version](results/kitsune-versions.md)
- Track specifications, the retired running guide, the Codex harness notes, pre-registered experiment protocols and
  analysis notes were removed from `main`. Read them in the
  [last pre-migration source tree](https://github.com/junyeong-nero/kitsune-benchmark/tree/1ef91e1/docs), which also
  holds the code those reports ran.
