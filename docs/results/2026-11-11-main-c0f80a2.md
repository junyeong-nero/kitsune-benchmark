**Bottom line:**

- **Both targets solve every lite unit.** 306/306 runs are scorable in one invocation: no stop, no setup retry.
  Kitsune 167/167, Playwright 139/139 (on `ad04bac` it missed `co-typing-01` v1). MDN advisory answer 2/2 each,
  MiniWoB++ 7/7 each.
- **The five Kitsune fixes since `ad04bac` hold where the suite exercises them** (candidates K1–K3, K5, K6 of the
  previous report):
  - one-option list (#483): `mw-book-flight` lists only the option, and its click selects it. Clicks on the menu
    `<ul>`: 1 → 0; requests 11 → 9;
  - line breaks in a single-line field (#484): `pb-handoff-04` saves its reply once in all 4 Kitsune runs (`ad04bac`:
    3 of 4 saved twice); requests 8 → 6 in personal v0, v1 and coexistence;
  - collapse by size (#485): collapse markers 101 → 19; targeted snapshots after a marker 12 → 1 (the remaining one is
    `ui-infinite`); no `ui-table` or `mm-grid` expansion;
  - tab-target hint (#487): no agent passed a tab as a target in this cohort (`ad04bac`: 2), so it is not exercised;
  - `tabs new`/`select` results (#488): mean 851 → 520 characters for `new`, 622 → 292 for `select`.
- **Input, Kitsune/Playwright on jointly solved units, `ad04bac` → `c0f80a2`:** personal 0.854 → **0.809**, crowded
  0.695 → **0.568**, isolated 0.777 → 0.921, coexistence 0.858 → **0.785**, external 0.916 → 0.952.
  - The isolated rise is one run: `mm-video`, where the agent sampled the video by screenshots and missed the red
    frame for 23 requests (91,259 → 398,728 tokens). Without `mm-video` and `ui-infinite`, isolated is 0.860 → 0.818.
  - On units both targets solved in both cohorts, without those two outliers, Kitsune's own input fell 4.0% and
    Playwright's rose 3.0%. Kitsune: personal −2.2%, crowded −6.7%, isolated −2.4%, coexistence −2.9%, external −12.0%.
- **Coexistence unchanged:** Kitsune never moved the user's view (Playwright did in 26 of 28 runs). The typing user
  kept their input in 3/3 Kitsune runs and 0/3 Playwright runs (0 against 372 misdirected characters).
- **The opt-in scripting changes (#513–#515) are not exercised:** the suite runs Kitsune's default tool surface, the
  same 23-tool allowlist as before.

One attempt, no order counterbalancing; read differences as observations.

## Setup

- **Kitsune:** main **`c0f80a2`** (`v0.7.3-24-gc0f80a2`), clean clone in `artifacts/vendor/kitsune-main-c0f80a2/`.
  It is `ad04bac` plus:
  - a tab target's error hint is the select step, not the generic selector list (#487, PR #489);
  - line breaks typed into a single-line `<input>` become spaces (#484, PR #490);
  - a one-option menu lists its option, not the menu around it (#483, PR #491);
  - `browser_tabs new` and `select` return the current tab and the tab count, not the whole list (#488, PR #492);
  - a collapsed run lists its items when their lines total at most 600 characters (#485, PR #493);
  - opt-in trusted Python scripting and a usage-based minimal toolset when scripting is on (#513, #514, #515, PR #516).
    Off by default; not used here.
- **Model and harness:** `claude-opus-5-5`, medium; Claude Code `2.1.303` on the subscription. Playwright MCP
  `0.0.83`, same 23-tool allowlist.
- **Benchmark:** `53d6a9b` (`taskset-v3.5-13`, clean). Since `bf08938` (the `ad04bac` cohort) only reports and the
  kitsune#485 A/B runner (`scripts/run-k485.py`) changed; no task, page or grader.
- **Plan:** `scripts/run-full-suite.py --plan lite --retry-setup-failures 1 --elicitation decline`, 306 agent runs.
  Personal, gallery and external ran the two targets concurrently; coexistence ran paired.
- **Run:** one invocation, 2026-11-11 12:10–14:03 KST (1 h 53 min). No entry stopped; every `setup_retries` is empty.
- **Preflight (no model calls):**
  - `doctor`: subscription login, no API key.
  - Unit tests: 410 pass, 18 skipped.
  - The native personal tests against `c0f80a2` (`PERSONAL_BROWSER_TEST=1 PERSONAL_KITSUNE_TEST=1`, 49 tests) pass.
    `KITSUNE_PROJECT` must be an absolute path: the bridge starts with the temporary folder as its working directory,
    so a relative path fails every subtest with "Test browser/bridge exited".
  - The native coexistence and viewport checks were not run; they are known to fail since kitsune#448 and v0.7.2
    ([#136](https://github.com/junyeong-nero/kitsune-benchmark/issues/136),
    [#137](https://github.com/junyeong-nero/kitsune-benchmark/issues/137)).

**Offline audit:**

- 306/306 runs `completed_unscored` and scorable, every one on `claude-opus-5-5`.
- No audit violations, harness errors or missing allowlisted tools.
- 112/112 personal runs asserted the 1280×720 content viewport.
- Every entry's stderr is empty.

## Outliers

- **`mm-video`, isolated (K/PW 2.20, 398,728 vs 181,262).** The video is 8 s long and the red frame shows at about
  1.6–3.2 s. The agent took screenshots while the video played and caught blue, yellow, green and purple but not red,
  then stepped through it by play/pause clicks, 54 calls in 23 requests. On `ad04bac` it took 8 requests. Nothing in
  the media path changed, so this reads as sampling luck in one attempt, not a regression.
- **`live-steam-goty-2025-negative-100h`, external (1.49).** 15 calls vs 14 (Kitsune: `tabs find navigate find
  navigate find find click snapshot click snapshot click click find find`). Live site, not graded.
- Eight personal and coexistence units sit at 1.10–1.45, the largest `pb-research-01` coexistence (78,300 vs 54,154,
  8 calls each). Not traced further.
