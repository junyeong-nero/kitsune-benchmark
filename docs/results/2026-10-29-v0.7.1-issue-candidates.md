# Issue and improvement candidates from the Kitsune v0.7.1 cohort

[v0.7.1 report](2026-10-29-opus-subscription-v0.7.1.md) · [Hostile-UI matrix](../hostile.md) ·
[Results index](README.md)

**Data and method.** An offline review of the 306 runs of the
[v0.7.1 release cohort](2026-10-29-opus-subscription-v0.7.1.md) and of the v0.7.1
[hostile-UI matrix](2026-10-29-opus-subscription-v0.7.1.md#hostile-ui-matrix-on-v071-no-model-synthetic-input). No
new model calls were made. Each candidate cites the runs it rests on. Most are single-attempt observations, so they
need a check before anyone claims an effect.

## Context

- Kitsune made **one tool error in 306 runs**: a `stale_ref` in `fill_form`, which it recovered from. Its costs come
  from paths, not errors.
- Kitsune/Playwright input per paired unit is below 0.9 in 77 of 139 units and above 1.10 in 19. The candidates below
  come from those 19.
- **Excluded, because Playwright does the same:**
  - starting a run with `browser_tabs list`/`select` (Kitsune 27/28 personal runs, Playwright 23/28);
  - blind `wait_for {time}` calls (gallery: Kitsune 11, Playwright 9).

## Candidates

### 1. Post-action deltas miss results that appear after the action (medium after repeats; kitsune#348)

Clicks, typing and fills return a delta taken right after the event. Results that render a moment later are missing:

- a status line ("우산 — 완료");
- a confirmation ("신청되었습니다.");
- an autocomplete list.

The agent then spends one to three observation rounds checking.

| Unit | K/PW input | What the delta showed | What the agent did next |
| --- | ---: | --- | --- |
| `pb-safe-03` v1 (v0: 1.26) | 1.31 | only the clicked button | `snapshot`, `wait_for {time: 1}`, `snapshot` |
| `ui-shadow` isolated | 1.36 | `fill_form`: only the last checkbox; `click`: only the button | a full `snapshot` after each |
| `mw-use-autocomplete` | 1.25 | `type "Al"`: only the textbox, no suggestions | `snapshot`, `take_screenshot`, `find "Aland"` |
| `mw-book-flight` | 2.21 (33 vs 18 calls) | `type "Wenatchee"`: no suggestion list | `find "(EAT)"` returned 0 several times; retyped, `fill_form`, `press_key` |

**Repeats** (4 counterbalanced pairs per unit, ABBA, Kitsune v0.7.1, 2026-10-29; all 32 runs successful):

| Unit | Pooled K/PW input | Per pair | Observation right after an action, PW / K |
| --- | ---: | --- | --- |
| `ui-shadow` isolated | 1.14 | 1.72, 1.37, 1.37, 0.65 | 5/9 vs **8/8** |
| `mw-use-autocomplete` | 1.15 | 1.21, 1.37, 1.02, 1.01 | 11/16 vs 10/16 |
| `pb-safe-03` v1 | 1.09 | 1.31, 1.02, 1.02, 1.02 | 4/4 vs 4/4 |
| `mw-book-flight` | 1.24 | 1.15, 0.94, **1.97**, 0.97 | 23/38 vs 22/38 |

- **Holds:** `ui-shadow`, where Kitsune's agent re-observes after every action; `use-autocomplete` has a smaller,
  consistent excess.
- **Mostly variance:** `mw-book-flight`'s 2.21. Its medians are close (129k vs 136k), and one pair of four is high.
- **Severity:** lowered from high to medium.

**Proposal:**

- After an action, let the delta wait briefly for the DOM to settle (a mutation-quiet window bounded by a few hundred
  ms, or until a pending request the action started completes).
- Include newly visible text and newly shown popups, listboxes and status regions anywhere in the document, not only
  under the target. #329 already keeps opened popups in snapshots.
- Report "no visible change yet" when nothing changed, so the agent knows to wait rather than re-read.

### 2. A link click does not say whether it navigated (medium; kitsune#349)

- **`live-steam` (1.48):**
  - `browser_click` on the winner capsule (`link ""`) returned `ok` with a delta of the *same* page.
  - The agent then called `browser_navigate` with the link's URL itself.
- **Proposal:** when a click starts a navigation, say so: `navigated: {url}` once committed, or
  `navigation_pending: true`. Otherwise state that the URL did not change.

### 3. `browser_hover` and `wait_for {time}` return no observation (medium; kitsune#350)

- **`ui-infinite` crowded (1.41, 22 vs 6 calls):** the agent alternated `hover` on the "불러오는 중…" sentinel and
  `wait_for {time: 2}` six times, then called `find` to see whether item #71 had loaded.
  - Both tools return about 23 characters (`ok`, `slept`).
  - The hover did load a batch each time, but nothing said so.
- **Proposal:** return the same post-action delta as a click from `hover`, and from a condition-less `wait_for`: what
  appeared or changed since the call started.

### 4. Synthetic pointers cannot be captured, held or moved continuously (medium; no-model matrix; kitsune#351)

On v0.7.1, from the [hostile matrix](2026-10-29-opus-subscription-v0.7.1.md#hostile-ui-matrix-on-v071-no-model-synthetic-input):

| Component | Result |
| --- | --- |
| `pointer-capture-drag` | The drop mark has a ref now (#341), but the page reports `setPointerCapture: Invalid pointer id`. A synthetic pointer is not one the browser tracks. Playwright's drag is accepted |
| `long-press` (600 ms hold) | No tool can hold a press. Both servers fail |
| `hover-intent` (several moves over 400 ms) | `browser_hover` sends one move. Both servers fail |

**Proposal:**

- An OS-input drag, for example `browser_trusted_drag`, or a `browser_drag` fallback to OS input when the page
  rejects the synthetic pointer.
- A `hold_ms` option on clicks.
- A `duration_ms`/`moves` option on hover. With synthetic events these satisfy timing checks; only pointer capture
  needs OS input.

### 5. Cross-origin iframe content is opaque (open: kitsune#343)

Unchanged on v0.7.1. Playwright clicks the button inside the frame; Kitsune lists the frame as `content=cross_origin`.

### 6. Asking in chat instead of the page's hand-off control (low; investigate; kitsune#352)

- **`mm-audio`:** the correct action is the hand-off button "직접 확인할 수 없어요 — 사용자에게 요청" (`ref=e90`), which
  was in Kitsune's snapshot.
  - Kitsune's agent took one snapshot and asked the user in chat instead (`no_attempt`). This happened in 2 of 7
    Kitsune `mm-audio` runs across the v0.7.0 and v0.7.1 cohorts.
  - Playwright's agent took that path in 0 of 7.
- **Hypothesis to test:** Kitsune's initialize instructions nudge agents toward asking the user. Compare the
  instructions text with and without the "ask the user" wording, in a model A/B on `mm-audio` and `judge-gate`.

### 7. A stale ref after an earlier action (low)

`coexistence-user-seeded/pb-safe-02`: one `fill_form` returned `stale_ref` and recovered on the next call. One
occurrence; it is listed only so the count is tracked.
