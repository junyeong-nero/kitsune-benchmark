# `taskset-v3.2` on Kitsune main `514b5b7`: lite suite with user-seeded personal tabs

[Results index](README.md) · [Results by Kitsune version](kitsune-versions.md) ·
[Previous: main `514b5b7` on `taskset-v3.1.2`](2026-11-01-main-514b5b7.md)

**Bottom line:**

- **Same Kitsune, new taskset.** This is the `514b5b7` lite suite again. Only the benchmark changed: since #70
  (`taskset-v3.2`) the personal track's starting tabs are opened by the user over WebDriver BiDi. Kitsune now lists
  them as the user's (`seeded_owned_by_agent` 0 in all 56 Kitsune personal runs). Before, they were agent-owned.
- **Successes:** 306/306 runs scorable. Kitsune solves every lite unit. Playwright misses `co-typing-01` v1 (wrong
  answer).
- **Personal holds:** 16 of 56 Kitsune runs had a viewed-tab hold, up from 11 on `taskset-v3.1.2`. The new ones are
  `pb-tabs-01` (v0, v1), `pb-account-01` (v0, v1) and `pb-safe-03` (v1). None went away. Every hold was declined and
  redone in another tab.
- **The cost per held unit is unchanged; there are more of them.** Personal K/PW input is 1.386 on the 16 held units
  and 0.839 on the 40 without (`taskset-v3.1.2`: 1.385 on 11, 0.841 on 45). The personal ratio rises from 0.934 to
  **0.973**, and calls from 1.105 to 1.179.
- **Control:** coexistence user-seeded already seeded user tabs and is unchanged (0.992 → 0.977; holds 8 → 7). The view
  is kept 2/28 by Playwright and 28/28 by Kitsune. Kitsune keeps the typing user's input 3/3 (0 misdirected characters
  against 183 for Playwright).
- **No `user_tab` holds.** `514b5b7` holds only the tab the user is viewing (kitsune#364/#390). Writes to the other
  user tabs, including the protected note, are free until kitsune#393 (user tabs read-only) lands.

One attempt, no order counterbalancing; read differences as observations.

## Setup

- **Kitsune:** main **`514b5b7`** (`v0.7.1-27-g514b5b7`), the same clean clone as the
  [`taskset-v3.1.2` run](2026-11-01-main-514b5b7.md) (`artifacts/vendor/kitsune-main-514b5b7/`).
- **Model and harness:** `claude-opus-5-5`, medium; Claude Code `2.1.303` on the subscription. Playwright MCP
  `0.0.83`, same 23-tool allowlist.
- **Benchmark:** `a1805fa` (`taskset-v3.2-4-ga1805fa`). The four commits after the tag change the harness only: the
  `session_limit` stop reason (#86) and the disclosure test (#87). Grading is unchanged.
- **Plan:** `scripts/run-full-suite.py --plan lite`, elicitation `decline`, 306 agent runs. Personal, gallery and
  external ran the two targets concurrently; coexistence ran paired.

- **The stop (protocol exception):** the Kitsune setup of `ui-reviews` failed before any model request. The relay's
  `browser_navigate` returned an error after 15.2 s (`setup_failed`, `infrastructure_invalid`), and the suite stopped
  on that unscorable pair. The host was slow at the time: in that entry, setup `tabs new` took 1.5–7.5 s and
  `navigate` 3–15 s. On `taskset-v3.1.2` they took 0.2–1.6 s and 1.3–4 s (one 12.8 s), and in the retry 0.2–2.8 s
  and 1.0–3.9 s. `fseventsd` was at 77% CPU. The release protocol only reruns a track after a session limit. This
  rerun is an exception for a host failure with no model request, made with `run-full-suite.py --from` (#78).
- **Merged:** `merge-suites.py` wrote `opus-subscription-v3.2-main-514b5b7-merged`. Personal comes from the first
  run; `gallery-crowded-v0` (both targets) and everything after come from the retry. The first run's 21 Playwright
  and 13 Kitsune crowded pairs are not used.

**Offline audit (merged):** 306/306 runs `completed_unscored` and scorable; every run used `claude-opus-5-5`; no audit
violations, harness errors or missing allowlisted tools; 112/112 personal runs asserted the 1280×720 content viewport.

## Pilot before the suite

A six-task personal pilot (variant 0, 12 runs) on the same revisions ran first, to check #70's seeding with a model.
All 12 runs succeeded, and every Kitsune run listed its starting tabs as the user's. Five of the six Kitsune runs had
a hold, as in the suite. It is not pooled with the suite.

## Limits

- One attempt, Kitsune and Playwright concurrent; elapsed times are under shared load.
- The suite was rerun from `gallery-crowded-v0` after a host-side setup failure (above), about 40 minutes after the
  stop.
- Decline answers no to every prompt, which is not a real user.
- `514b5b7` predates kitsune#393. Until user tabs are read-only, this taskset measures only the viewed-tab hold on user
  tabs.
- The live tasks in external are ungraded.
