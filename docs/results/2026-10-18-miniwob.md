## Local process resource observations

Sampling: psutil 7.2.2, one-second interval plus phase/root boundary observations.
Values below use each target's **per-run task-phase** summary, not the pair-level
sum that also includes an idle Kitsune browser during the Playwright run.

| Metric | Playwright MCP | Kitsune MCP |
| --- | ---: | ---: |
| Sampled peak summed RSS, MiB | 1275.19 | 1387.28 |
| Time-weighted mean summed RSS, MiB | 876.34 | 1225.42 |
| Observed user CPU seconds | 2.959 | 0.929 |
| Observed system CPU seconds | 0.884 | 0.269 |
| Peak observed process count | 10 | 15 |
| Sampling errors | 0 | 0 |
| Unexpected live processes at run end | 0 | 0 |

**Summed RSS is not unique physical memory**: browser shared pages can be counted
multiple times. These are sampled, not exact lifetime peaks. CPU tails and
short-lived processes can be missed. Local CPU/RAM do not include remote GPT
inference. Web-ext launcher overhead is included and separately attributed in
Kitsune's component groups. Its persistent roots are explicitly managed by the
pair wrapper rather than mistaken for leaked processes.

The pair-level lifecycle trace has 65 samples, zero sampling errors, and zero
unexpected live processes after final cleanup. It records baseline/setup/ready,
Playwright work, Kitsune work, and cleanup separately.

## What this does and does not establish

Established: the same pinned Codex/model can perform an original external task
through either MCP; task success is read from original reward events rather
than self-report; explicit process-root collection captures both architectures.

Not established: a success-rate estimate, memory/CPU superiority, standard
MiniWoB leaderboard performance, complete prompt/tool attestation, or hardened
anti-cheating guarantees. The environment uses Firefox/MCP rather than standard
Chrome/Gym and an extended episode budget. It is one seed/task, fixed order,
with uncontrolled cache effects and unmatched effective viewports.

Startup timing also differs: Kitsune's browser/bridge are ready before its agent
run, while Playwright can launch inside its first tool call. Setup is visible in
the pair resource trace but is not part of the per-run task timing table.

## Reproduce

```sh
uv sync --locked
npm ci --ignore-scripts --no-audit --no-fund
npm run setup:firefox
uv run --locked python -m kitsune_benchmark benchmark --fetch
uv run --locked python -m kitsune_benchmark benchmark --execute
```

The execute command consumes subscription quota. The source fetch and default
benchmark plan do not invoke a model. Details: [external track (formerly the MiniWoB adapter)](../external.md)
and [resource collection](../resources.md).
