```sh
uv run --locked python scripts/run-five-way-main.py preflight \
  --out artifacts/claude-five-way-main-79eb955
uv run --locked python scripts/run-five-way-main.py run \
  --out artifacts/claude-five-way-main-79eb955 --continue-unstarted --limit 5

  --out artifacts/claude-five-way-main-79eb955 --continue-unstarted

  --out artifacts/claude-five-way-main-79eb955
```

Preflight files are exclusive-create; do not overwrite the recorded preflight. Bounded runs resume only
unattempted cells with identical manifests/source/policy. No episode retry, replacement, model fallback or
automatic quota-reset continuation. Under the previously approved `--continue-unstarted` policy, a normal
finish with zero episode starts, zero telemetry errors and `no_terminal_reward` remains unscorable/counts
as an attempt and may continue. Other unscorable/execution/quota/source/catalog errors stop for review.
