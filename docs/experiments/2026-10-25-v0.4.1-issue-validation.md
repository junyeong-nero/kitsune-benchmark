The two editing probes are **new diagnostic fixtures**, not additions or changes
to taskset-v1.2. They use independent page/server state for grading. A no-model
Playwright reference must complete both before any model execution. Keyboard
telemetry records actual changes, so final success via a workaround can be
separated from successful default key behavior. The prompt asks the model to
stop repeating an ineffective action after two attempts; that bounds recovery
cost and differs from the earlier unrestricted Gallery editor trace.

## Questions and decision rules

1. **Keys/editing:** does the model encounter the confirmed key no-op, detect it,
   recover via another allowed operation, or fail/report inability? Report final
   goal success separately from per-key effects and explicit no-whole-value-
   replacement contract compliance. Do not call a successful workaround a fix
   to the underlying key behavior.
2. **Tables:** do extra model requests/input recur across repeated identical
   tasks in both target orders? Report paired ratios, medians and ranges of
   input, MCP calls and model requests on joint successes, alongside all results.
   Four repetitions can corroborate an observation, not establish a general
   causal release improvement. No candidate optimization is being tested.
3. **Native setup:** does the previously unscorable four-tab task reproduce its
   preparation failure? Three repetitions cannot establish a rare issue is
   fixed if all pass. Preserve phase/evidence for any failure.
4. **Slider:** does the model again choose fill_form, receive the unsupported
   recovery hint and recover? Distinguish UI outcome from whether the erroneous
   hint was exercised at all.
5. **Relay lifecycle / grading confounders:** retain the deterministic no-model
   relay proof and existing ownership/CAPTCHA evidence. Do not waste inference
   to re-prove an upstream process exit or force CAPTCHA-policy outcomes.

Each final issue-table row will state: new/existing issue, priority, model and/or
no-model evidence, successful/attempted coverage, uncertainty, and recommendation
(post now, append evidence, investigate, or hold). Raw errors and failed attempts
are retained, not silently excluded.
